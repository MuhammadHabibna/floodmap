Validasi Data & Performa Model

Model ini dilatih pada 1.445 citra latih beresolusi 480×640 piksel. Analisis Exploratory Data Analysis (EDA) mendeteksi fenomena extreme long-tail imbalance, di mana kelas water mendominasi (56.4%) dibandingkan kelas langka seperti tree (0.18%). Oleh karena itu, pendekatan Triple Loss (CrossEntropy + Lovász-Softmax + Focal Loss) digunakan untuk memaksa model memperhatikan objek kecil (seperti vehicle dan rumah).

Gap antara skor Val mIoU (~0.64) dan skor uji publik LB (~0.49) telah diinvestigasi: terdapat kebocoran data (Data Leakage) masif (77.8%) di mana citra set validasi hampir identik dengan set pelatihan. Menggunakan Test-Time Augmentation (TTA) terbukti krusial untuk menjaga ketahanan model pada data uji eksternal.
